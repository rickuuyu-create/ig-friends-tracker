IG FRIENDS TRACKER - QUICK START
================================

Run your own copy in 5 steps (all free):

1. Install Node.js 18+ from https://nodejs.org

2. In this folder, run:
     npm install

3. Create a free Firebase project at https://console.firebase.google.com
   - Add a Web app and copy its config values
   - Authentication -> Sign-in method -> enable "Google"
   - Enable "Google Sheets API" and "Google Drive API" at
     https://console.cloud.google.com/apis/library
     (skipping this causes "Failed to save" errors!)

4. Copy .env.example to .env.local and fill in the six
   VITE_FIREBASE_* values from step 3.

5. Run:
     npm run dev
   Open http://localhost:3000 and sign in with Google.

Your data is saved to a Google Sheet named "IG Friends Database"
inside YOUR OWN Google Drive. Nothing is stored anywhere else.
